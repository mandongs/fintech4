문제 정의
Problem Statement — 청년들이 실제로 겪는 불편함
💡 아래 3가지 문제는 실제 청년 사용자 인터뷰 및 온통청년 플랫폼 리뷰 분석을 통해 도출된 핵심 Pain Point입니다.

🔍 문제 1. 정보 파편화

정부, 지자체, 시중은행, 공공기관이 각자 다른 채널에서 지원 정책을 공지. 청년이 직접 수십 개 사이트를 돌아다니며 확인해야 함.

⏰ 문제 2. 마감 공고 미인지

모집 기간이 1~3개월로 짧고, 다음 공고까지 수개월 대기. 적시에 알림을 받지 못해 기회를 놓치는 경우가 다수 발생.

🤷 문제 3. 조건 파악 어려움

중위소득, 기준 중위소득 비율, 가구원 수 등 복잡한 조건 용어를 이해하기 어려워 자신이 신청 가능한지 스스로 판단 불가.

✅우리의 해결책

→ 해결 1. 통합 수집

API + 자동 배치 수집으로 정책·금융상품 데이터를 매일 최신화. 한 플랫폼에서 모두 검색.

→ 해결 2. D-day 알림

북마크 정책의 마감일 D-7·D-3·D-1에 자동 이메일 알림 발송. 중요한 공고를 절대 놓치지 않도록.

→ 해결 3. AI 맞춤 상담

Gemini AI가 조건을 자연어로 설명. "나 받을 수 있어?"에 즉시 답변.

핵심 기능 정의
Core Features — 4대 기능이 어떻게 문제를 해결하는가
🎯 기능 1. 스마트 프로파일링 & 매칭 엔진
사용자가 입력한 조건(나이·소득·지역·고용 상태 등)을 7가지 가중치 알고리즘으로 분석해 매칭 점수(0~100%)를 산출하고 상위 정책을 자동 정렬합니다.
매칭 기준가중치평가 방식
나이 조건30%min_age ≤ 사용자 나이 ≤ max_age
소득 조건25%연소득 기준 구간 충족 여부
지역 조건20%시도코드 매칭 (전국 = 100%)
직업 조건10%고용 형태 코드 매칭
학력 조건5%재학/졸업 상태 매칭
결혼 상태5%미혼/기혼/한부모 매칭
마감 임박도5%D-30 이내 가산점 부여
⏰ 기능 2. D-day 마감 관리 & 알림
관심 정책을 북마크하면 마감일을 자동 추적합니다. D-7·D-3·D-1에 이메일 알림을 자동 발송하며, 메인 화면에 마감 임박 정책을 강조 표시합니다.
  • 다양한 날짜 형식 자동 파싱 (예: "20260301 ~ 20260430", "상시", "연중")
  • D-1(빨강), D-7(노랑), 상시(초록) 컬러 뱃지로 긴급도 시각화
  • 북마크 정책별 알림 ON/OFF 개별 설정 가능
  • 매일 오전 9시 자동 알림 스케줄러 실행 (APScheduler)
  • 이메일 알림 템플릿: 정책명, 마감일, 신청 링크 포함
🤖 기능 3. AI 자연어 상담 (Gemini RAG)
Google Gemini 2.5 Flash 모델과 FAISS 벡터 검색을 결합한 RAG(Retrieval-Augmented Generation) 구조로, 사용자 질문에 정책 DB 기반 정확한 답변을 제공합니다.
  • "나 취업 준비 중인데 받을 수 있는 지원금이 있어?" → 조건 분석 후 해당 정책 안내
  • 사용자 프로필(나이·소득·지역) 자동 반영하여 개인화 답변
  • 대화 히스토리 최근 6턴 유지로 맥락 이해 상담
  • FAISS 벡터 DB에서 의미론적 유사 정책 5개 실시간 검색
  • 빠른 질문 4가지 프리셋 제공 (원클릭 질문)
💳 기능 4. 금융상품 매칭 추천
금융감독원 API로 수집한 996개 금융상품 중 사용자 나이·소득·고용 상태에 맞는 청년 특화 상품(적금·예금·대출)을 자동 추천합니다.
  • 상품 유형별 탭 필터 (전체 / 적금 / 예금 / 전세대출 / 주택담보대출 / 신용대출)
  • 청년 특화 상품 우선 노출 (is_youth_product 플래그)
  • 최대 금리·한도·가입 방법 핵심 정보 카드 형태 표시
  • FSS API 월 1회 자동 갱신으로 최신 상품 유지
