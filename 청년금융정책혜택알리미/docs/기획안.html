청년 금융정책 혜택 알리미 기획안

1. 프로젝트 개요

  • 서비스명: 청년 금융정책 혜택 알리미
  • 목적: 청년 사용자가 본인 상황에 맞는 정책과 금융상품을 빠르게 찾고, 마감일을 놓치지 않도록 돕는 개인화 추천 서비스 제공
  • 핵심 가치
  • 흩어진 청년정책 정보를 한곳에서 탐색
  • 프로필 기반 맞춤 추천으로 탐색 시간 단축
  • 북마크와 D-day 알림으로 신청 기회 손실 최소화
  • AI 상담으로 복잡한 조건 이해 지원

2. 배경 및 문제 정의

  • 청년 대상 정책과 금융 혜택은 기관별로 분산되어 있어 찾기 어렵다.
  • 정책별 연령, 소득, 지역, 혼인상태, 직업, 학력 조건이 달라 직접 비교가 번거롭다.
  • 신청 기간이 짧거나 수시 마감되는 경우가 많아 적시에 확인하지 못하면 혜택을 놓치기 쉽다.
  • 금융상품 또한 청년 우대 여부와 가입 조건을 한눈에 파악하기 어렵다.

3. 목표

  • 사용자가 기본 프로필만 입력하면 맞춤형 정책 추천 목록을 받을 수 있도록 한다.
  • 청년 맞춤 금융상품을 유형별로 추천하고 추천 사유를 제공한다.
  • 관심 정책을 북마크하고 마감 임박 정책을 한 화면에서 관리할 수 있도록 한다.
  • AI 상담 기능을 통해 정책 조건, 준비 서류, 신청 방법 등을 자연어로 질의할 수 있도록 한다.

4. 타깃 사용자

  • 만 19세~34세 중심의 청년층
  • 취업 준비생, 사회초년생, 청년 1인 가구
  • 청년 전세, 주거, 저축, 대출, 창업 지원 제도에 관심 있는 사용자
  • 복잡한 공공정책 정보를 쉽게 이해하고 싶은 사용자

5. 핵심 기능

5.1 회원 및 인증

  • 이메일 회원가입 및 로그인
  • JWT 기반 인증 유지
  • 보호 라우트로 로그인 사용자만 핵심 기능 이용 가능

5.2 사용자 프로필 등록

  • 생년월일, 연소득, 지역명/지역코드, 혼인상태, 고용형태, 직업코드, 학력코드 입력
  • 입력 정보를 기준으로 사용자 페르소나 자동 분류
  • 추천 정확도 향상을 위한 개인화 기준 데이터 확보

5.3 맞춤 정책 추천

  • 프로필 기반으로 청년정책 조건 매칭
  • 정책별 매칭 점수 제공
  • 신청 마감일까지 남은 일수 표시
  • 정책 상세 페이지에서 지원 내용, 신청 방법, 참고 링크 확인

5.4 맞춤 금융상품 추천

  • 적금, 예금, 전세대출, 주택담보대출, 신용대출 유형별 추천
  • 청년 특화 상품 여부 표시
  • 추천 사유 및 한도 정보 제공

5.5 북마크 및 알림

  • 관심 정책 북마크 등록/해제
  • 북마크 목록 확인
  • 마감 7일 이내 정책 강조 표시
  • 알림 페이지에서 마감 임박 정책과 저장 정책 통합 관리

5.6 AI 상담

  • 사용자의 질문을 자연어로 입력
  • 사용자 프로필과 추천 정책을 참고해 맞춤형 답변 제공
  • 자주 묻는 질문 버튼으로 빠른 진입 유도

6. 사용자 시나리오

시나리오 1. 처음 방문한 사용자

  1. 회원가입 후 로그인한다.
  2. 프로필 페이지에서 생년월일과 소득, 지역, 직업 정보를 입력한다.
  3. 추천 페이지에서 본인 조건에 맞는 청년정책 목록을 확인한다.
  4. 관심 정책을 북마크한다.

시나리오 2. 전세 지원이 필요한 사용자

  1. 금융상품 페이지에서 전세대출 탭을 선택한다.
  2. 청년 특화 여부와 한도, 추천 이유를 확인한다.
  3. AI 상담에 전세대출 조건을 질문해 추가 설명을 받는다.

시나리오 3. 마감일 관리를 원하는 사용자

  1. 관심 있는 정책을 여러 개 북마크한다.
  2. 알림 페이지에서 D-day 기준으로 마감 임박 정책을 확인한다.
  3. 외부 링크로 바로 이동해 신청을 진행한다.

7. 기대 효과

  • 청년정책 탐색 시간 단축
  • 개인 맞춤 추천으로 정책 접근성 향상
  • 마감일 기반 관리로 신청 누락 방지
  • 금융상품 비교와 상담 경험 개선

8. 차별화 포인트

  • 정책 추천과 금융상품 추천을 하나의 서비스에서 함께 제공
  • 조건 기반 추천과 D-day 관리 기능을 동시에 제공
  • AI 상담을 통해 정책 설명을 탐색형이 아닌 대화형으로 제공
  • 청년 사용자 특화 입력 항목과 추천 로직 반영

9. MVP 범위

  • 포함
  • 회원가입/로그인
  • 프로필 등록
  • 정책 추천 목록 및 상세 조회
  • 금융상품 추천 목록
  • 북마크 및 D-day 알림 화면
  • AI 상담
  • 제외 또는 후순위
  • 푸시 알림, 문자, 이메일 발송 고도화
  • 관리자 CMS
  • 정책 신청 자격 자동 증빙 연동
  • 소셜 로그인

10. 성공 지표 예시

  • 회원가입 대비 프로필 등록 완료율
  • 추천 페이지 진입 사용자 중 정책 상세 조회 비율
  • 북마크 등록률
  • AI 상담 사용률
  • 마감 임박 정책 클릭률

11. 향후 확장 방향

  • 지역별 청년정책 맞춤 필터 고도화
  • 정책 요약 카드 자동 생성
  • 알림 채널 확대
  • 사용자 행동 기반 추천 품질 개선
  • 정책 데이터 수집 자동화 및 관리자 운영 화면 추가
