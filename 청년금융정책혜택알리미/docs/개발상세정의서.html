서비스 레이어 설계
핵심 비즈니스 로직인 매칭 엔진의 동작 방식을 상세히 기술합니다.
가중치 매칭 엔진 (matching.py)
프로필이 있는 사용자에 한해 실행됩니다. 7가지 기준을 가중치로 합산하여 0~1 사이의 match_score를 산출하고, 상위 20개를 반환합니다.
기준가중치계산 방식프로필 필드
나이 (Age)30%정책 min_age ~ max_age 범위 내이면 1.0, 벗어날수록 감점birth_date
소득 (Income)25%정책 earn_min ~ earn_max 범위 내이면 1.0income_level
지역 (Region)20%target_region이 NULL이면 1.0, 사용자 region 포함 여부region
직업 (Job)10%target_job과 job_status 문자열 매칭job_status
재학 (School)5%재학생 조건 있을 때 is_student 일치 여부is_student
결혼 (Marriage)5%기혼 조건 있을 때 is_married 일치 여부is_married
마감 임박 (Deadline)5%D-7 이내 정책에 보너스 점수 부여days_left
# matching.py 핵심 로직 (pseudocode) def calc_match_score(policy, user_profile) -> float: score = 0.0 # 나이 점수 (30%) age = calc_age(user_profile.birth_date) if (policy.min_age or 0) <= age <= (policy.max_age or 999): score += 0.30 # 소득 점수 (25%) if user_profile.income_level: score += 0.25 * check_income(policy, user_profile.income_level) # 지역 점수 (20%) if not policy.target_region or user_profile.region in policy.target_region: score += 0.20 # 직업/재학/결혼 (각 5~10%) ... 생략 # 마감 임박 보너스 (5%) if policy.days_left is not None and 0 <= policy.days_left <= 7: score += 0.05 return min(score, 1.0)

답변 반환
단계별 상세
  1. 사용자 질문 수신: POST /chat/message로 message와 JWT 토큰을 받습니다. 토큰에서 user_id를 추출해 프로필을 조회합니다.
  2. 임베딩 변환: google-genai SDK의 embed_content() 호출. 모델: text-embedding-004, task_type: RETRIEVAL_QUERY. 768차원 벡터 반환.
  3. FAISS 유사도 검색: faiss_index.bin에서 코사인 유사도 기준 상위 5개 문서 검색. policy_docs.pkl에서 원문 텍스트 조회.
  4. 컨텍스트 조립: 시스템 프롬프트 + 사용자 프로필 요약 + 검색된 정책 5개 텍스트 + 사용자 질문을 하나의 프롬프트로 구성.
  5. Gemini 텍스트 생성: gemini-2.5-flash 모델로 generate_content() 호출. 한국어, 친근한 말투, 나이 언급 포함 시스템 인스트럭션 적용.
  6. 응답 반환: { reply: string, sources: [policy_id, ...] } 형태로 반환.

FAISS 인덱스 빌드 코드
# 최초 1회 또는 정책 데이터 대량 업데이트 시 실행 def build_faiss_index(db_session): policies = db_session.query(Policy).all() texts, embeddings = [], [] for p in policies: doc = f"{p.name} {p.category_main} {p.description} {p.support_content}" result = client.models.embed_content( model="text-embedding-004", contents=doc, config=types.EmbedContentConfig(task_type="RETRIEVAL_DOCUMENT") ) embeddings.append(result.embeddings[0].values) texts.append(doc) matrix = np.array(embeddings, dtype=np.float32) faiss.normalize_L2(matrix) index = faiss.IndexFlatIP(matrix.shape[1]) # cosine similarity index.add(matrix) faiss.write_index(index, "data/faiss_index.bin") pickle.dump(texts, open("data/policy_docs.pkl", "wb"))

security.py 구현
import bcrypt from jose import jwt, JWTError def hash_password(password: str) -> str: salt = bcrypt.gensalt() return bcrypt.hashpw(password.encode("utf-8"), salt).decode("utf-8") def verify_password(plain: str, hashed: str) -> bool: return bcrypt.checkpw(plain.encode("utf-8"), hashed.encode("utf-8")) def create_access_token(data: dict, expires_delta: timedelta) -> str: to_encode = data.copy() to_encode["exp"] = datetime.utcnow() + expires_delta return jwt.encode(to_encode, settings.SECRET_KEY, algorithm="HS256") def decode_token(token: str) -> dict: try: return jwt.decode(token, settings.SECRET_KEY, algorithms=["HS256"]) except JWTError: raise HTTPException(status_code=401, detail="Invalid token")
